# PLC 与平台通讯接口整改清单

> 适用对象：PLC 程序工程师、平台联调工程师  
> PLC 工程基线：`TIA_V21_Offline_Export_2026-11-23`  
> 平台接口基线：2026-11-24 当前代码  
> 通讯方式：Siemens S7（ISO-on-TCP，TCP 102），平台使用 Apache PLC4X 1.0.0

## 1. 整改结论

PLC 工程师按以下范围修改并回填地址：

- [ ] 保留 DB100 现有控制、通道选择、实时数据和配方字段的绝对地址。
- [ ] 保留 DB12 现有 15 个报警位的绝对地址。
- [ ] 新增或明确一个供平台读取的通讯反馈区：当前通道、模式、动作、运行状态、自动阶段、采样序号、故障码。
- [ ] 新增或明确六个独立的通道位移清零 BOOL 命令点。
- [ ] 使所有反馈值保持为当前状态，不得只输出一个扫描周期的脉冲。
- [ ] 确保 DB100 平台参数能进入实际控制逻辑，不能出现平台回读成功但 PLC 仍使用 DB16/HMI 旧值。
- [ ] 手动目标位移复用 DB100 各通道原有“顶升距离”字段，不新增手动目标地址。
- [ ] 自动测量完整时序、安全联锁、稳定点判定和完成判定继续由 PLC 负责。

所有未确定地址在本清单中留空，由 PLC 工程师分配后回传。平台不得猜测地址。

## 3. DB100 现有控制点：地址保持不变

平台对以下 BOOL 点发送脉冲。PLC 必须将脉冲转为实际命令，并通过第 7 节反馈区返回执行后的状态。

| 命令 | PLC4X 地址 | 业务含义 | PLC 应答 |
|---|---|---|---|
| 手动 | `%DB100.DBX0.0:BOOL` | 接通/断开手动模式 | 模式变为 `1`/`0` |
| 自动 | `%DB100.DBX0.1:BOOL` | 接通/断开自动模式 | 模式变为 `2`/`0` |
| 手动快泄 | `%DB100.DBX0.2:BOOL` | 当前通道手动快泄 | 动作变为 `4` |
| 手动启动 | `%DB100.DBX0.3:BOOL` | 手动模式启动控制 | 动作变为 `1` |
| 停止 | `%DB100.DBX0.4:BOOL` | 停止当前动作 | 运行状态变为 `0`，动作变为 `0` |
| 暂停/继续 | `%DB100.DBX0.5:BOOL` | 运行时切换暂停与继续 | 运行状态在 `2` 与 `1` 间切换 |
| 上升 | `%DB100.DBX0.6:BOOL` | 当前通道手动上升 | 动作变为 `2` |
| 下降 | `%DB100.DBX0.7:BOOL` | 当前通道手动下降 | 动作变为 `3` |
| 自动测量 | `%DB100.DBX1.0:BOOL` | 启动当前通道完整自动流程 | 动作变为 `5`，运行状态变为 `1` |
| 自动快泄 | `%DB100.DBX1.1:BOOL` | 启动六通道自动快泄 | 动作变为 `6` |

## 4. DB100 通道选择：顺序不得改动

中轴顺序必须按现有 PLC 布局处理：**2 号是中轴2，3 号是中轴1**。

| 通道值 | 通道 | 平台编码 | 选择脉冲地址 |
|---:|---|---|---|
| 1 | 尾轴 | `TAIL_SHAFT` | `%DB100.DBX2.0:BOOL` |
| 2 | 中轴2 | `INTERMEDIATE_2` | `%DB100.DBX2.1:BOOL` |
| 3 | 中轴1 | `INTERMEDIATE_1` | `%DB100.DBX2.2:BOOL` |
| 4 | 飞轮 | `FLYWHEEL` | `%DB100.DBX2.3:BOOL` |
| 5 | 1# | `MAIN_ENGINE_1` | `%DB100.DBX2.4:BOOL` |
| 6 | 2# | `MAIN_ENGINE_2` | `%DB100.DBX2.5:BOOL` |

选择脉冲到达后，PLC 应在 3 秒内更新“当前通道”反馈。页面切换通道 Tab 不会写 PLC，只有接通手动或自动模式时才发送选择脉冲。

- [ ] 位移至少能稳定到 `0.01 mm`；顶升力至少能稳定到 `0.1 kN`。
- [ ] 自动采样序号递增时，对应通道的位移和顶升力已经稳定。
- [ ] 位移和顶升力保持到下一稳定点，不得先递增序号再更新测量值。

手动和自动共用每个通道原有的“顶升距离”字段。手动上升前平台写入手动目标；自动测量前平台用自动目标覆盖同一字段。

|---|---|---|---|---|
| 尾轴 | `%DB100.DBD204:REAL` | `%DB100.DBD208:REAL` | `%DB100.DBW212:INT` | `%DB100.DBD214:REAL` |
| 中轴2 | `%DB100.DBD230:REAL` | `%DB100.DBD234:REAL` | `%DB100.DBW238:INT` | `%DB100.DBD240:REAL` |
| 中轴1 | `%DB100.DBD256:REAL` | `%DB100.DBD260:REAL` | `%DB100.DBW264:INT` | `%DB100.DBD266:REAL` |
| 飞轮 | `%DB100.DBD282:REAL` | `%DB100.DBD286:REAL` | `%DB100.DBW290:INT` | `%DB100.DBD292:REAL` |
| 1# | `%DB100.DBD308:REAL` | `%DB100.DBD312:REAL` | `%DB100.DBW316:INT` | `%DB100.DBD318:REAL` |
| 2# | `%DB100.DBD334:REAL` | `%DB100.DBD338:REAL` | `%DB100.DBW342:INT` | `%DB100.DBD344:REAL` |

整改要求：

- [ ] 手动上升控制逻辑读取当前通道上述“顶升距离”，不得要求新增手动目标地址。
- [ ] 自动流程读取同一“顶升距离”及本表其余三项参数。
- [ ] 压力间隔是 `INT`、单位 MPa，不是力值间隔 kN。
- [ ] 平台写入后立即回读；PLC 不得在回读前被旧 HMI 配方周期性覆盖。
- [ ] 如果实际控制仍读取 DB16 `HMI_Basic`，应保留并验证 `MES_Control(DB100) → HMI_Basic(DB16)` 的同步方向和完整性。
- [ ] 参数值在本次动作结束前保持有效，PLC 内部安全限值仍由 PLC 强制执行。

平台不会下发标准值、总值、顶升系数或调整系数，这些值继续由平台计算或保存。

## 8. 状态枚举：必须完全一致

### 8.1 当前动作 `CurrentAction`

| 值 | 含义 | 保持规则 |
|---:|---|---|
| 0 | 空闲 | 无活动动作 |
| 1 | 手动已启动 | 手动模式已允许动作，但尚未上升/下降/快泄 |
| 2 | 手动上升 | 保持到停止或切换动作 |
| 3 | 手动下降 | 保持到停止或切换动作 |
| 4 | 手动快泄 | 保持到停止 |
| 5 | 自动测量 | 完整自动流程期间保持 |
| 6 | 自动快泄 | 六通道自动快泄期间保持 |

### 8.2 运行状态 `RunState`

| 值 | 含义 | 说明 |
|---:|---|---|
| 0 | 空闲 | 停止完成或没有运行 |
| 1 | 运行 | 命令已接受且动作正在运行 |
| 2 | 暂停 | 暂停期间保持，继续后回到 1 |
| 3 | 完成 | 自动流程正常完成；最终采样必须已准备好 |
| 4 | 故障 | 自动流程故障停止；`FaultCode` 必须非 0 |

### 8.3 自动阶段 `ProcessStage`

| 值 | 含义 | 平台用途 |
|---:|---|---|
| 0 | 等待 | 未进入自动流程 |
| 1 | 上升 | 页面显示对应通道顶升动画，采样记为上升 |
| 2 | 上升保持 | 稳定点采样记为上升 |
| 3 | 下降 | 采样记为下降 |
| 4 | 下降保持 | 稳定点采样记为下降 |
| 5 | 完成 | 结束状态；平台使用前一阶段判断最终采样方向 |

## 9. 自动采样序号规则

`SampleSequence` 是平台判断“出现新稳定点”的唯一触发信号，必须满足：

- [ ] 每次新的自动测量在确认启动前先置 `0`。
- [ ] 只有位移和顶升力达到本次稳定采样条件后才递增。
- [ ] 同一稳定点只递增一次，建议从 `1` 连续递增。
- [ ] 先锁存 DB100 当前通道位移、顶升力和阶段，再递增序号。
- [ ] 序号及本次稳定值保持到下一稳定点，不能输出瞬时脉冲。
- [ ] 最终稳定点先递增序号并保持数据，再将 `RunState` 置为 `3`。
- [ ] 故障流程将 `RunState` 置为 `4`，同时保持非零 `FaultCode`，直到复位或下一流程初始化。

平台按“运行 ID + 采样序号”幂等保存，保存内容只有位移和顶升力，不保存压力值。

## 12. 禁止出现的实现

- 不新增六个“手动目标位移”PLC 地址。
- 不把压力间隔改成力值间隔，也不把单位改成 kN。
- 不改变 DB100 中中轴2和中轴1的通道编号及地址顺序。
- 不让 HMI 周期任务把平台刚写入的 DB100 配方立即覆盖回旧值。
- 不把状态反馈和采样序号做成单扫描周期脉冲。
- 不在平台侧替代 PLC 编排自动上升、保持、下降和硬件联锁。
- 不使用优化 DB 的易变偏移作为平台绝对地址。
- 不在最终稳定采样写入前先清空序号、实时值或完成状态。
