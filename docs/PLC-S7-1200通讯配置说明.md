# S7-1200 通讯配置说明

## 软件与 PLC 的职责

Java 系统通过 Apache PLC4X 1.0.0 使用 S7 协议（ISO-on-TCP）读写 S7-1200。软件只负责下发按钮脉冲和参数、读取反馈及保存稳定采样；自动上升、保持、下降、安全联锁和完成判断由 PLC 程序负责。`DEVICE_MODE=PLC` 时通讯失败会报警并锁定控制，不会回退到模拟数据。

工作页切换通道 Tab 只改变页面当前通道和实时数据显示来源，不写 PLC。设置页和手动目标保存也只更新数据库。点击“接通手动”或“接通自动”时，后端只按“通道选择脉冲 → 通道反馈确认 → 模式脉冲 → 模式反馈确认”的顺序操作 PLC。手动目标在每次上升前写入并回读；自动控制参数在每次自动测量前写入并回读。

## TIA Portal 前置条件

- 开启 `Permit access with PUT/GET communication from remote partner`。
- DB100、DB12 和新增的 Java 通讯 DB 使用标准、非优化访问。
- Windows 服务器能访问 PLC 的 ISO-on-TCP 端口（默认 TCP 102）。
- PLC 工程提供下文所有反馈点、清零点和手动目标点，地址及枚举必须与现场程序一致。

## 运行配置

现场至少需要设置以下环境变量：

```powershell
$env:DEVICE_MODE = "PLC"
$env:PLC_HOST = "PLC实际IP"
$env:PLC_RACK = "0"
$env:PLC_SLOT = "PLC实际槽号"

$env:PLC_FEEDBACK_SELECTED_CHANNEL = "%DB实际地址:INT"
$env:PLC_FEEDBACK_MODE = "%DB实际地址:INT"
$env:PLC_FEEDBACK_ACTION = "%DB实际地址:INT"
$env:PLC_FEEDBACK_RUN_STATE = "%DB实际地址:INT"
$env:PLC_FEEDBACK_PROCESS_STAGE = "%DB实际地址:INT"
$env:PLC_FEEDBACK_SAMPLE_SEQUENCE = "%DB实际地址:DINT"
$env:PLC_FEEDBACK_FAULT_CODE = "%DB实际地址:INT"
```

六个通道还必须分别配置位移清零 BOOL 点和手动目标位移 REAL 点：

```text
PLC_ZERO_TAIL_SHAFT                   PLC_MANUAL_TARGET_TAIL_SHAFT
PLC_ZERO_INTERMEDIATE_1               PLC_MANUAL_TARGET_INTERMEDIATE_1
PLC_ZERO_INTERMEDIATE_2               PLC_MANUAL_TARGET_INTERMEDIATE_2
PLC_ZERO_FLYWHEEL                     PLC_MANUAL_TARGET_FLYWHEEL
PLC_ZERO_MAIN_ENGINE_1                PLC_MANUAL_TARGET_MAIN_ENGINE_1
PLC_ZERO_MAIN_ENGINE_2                PLC_MANUAL_TARGET_MAIN_ENGINE_2
```

未提供上述任一地址时，PLC 模式拒绝启动，避免使用猜测点位。连接、读写、反馈、轮询及脉冲时间可通过 `PLC_CONNECT_TIMEOUT_MS`、`PLC_READ_TIMEOUT_MS`、`PLC_WRITE_TIMEOUT_MS`、`PLC_FEEDBACK_TIMEOUT_MS`、`PLC_POLL_INTERVAL_MS`、`PLC_PULSE_MS` 调整，轮询和脉冲默认 200 ms。

## 固定点位

控制按钮和通道选择使用 DB100 的 BOOL 脉冲点；实时值和设置参数使用《点位表0505.xlsx》中的 DB100 地址。中轴点位顺序必须特别注意：中轴2选择点为 `DB100.DBX2.1`，中轴1为 `DB100.DBX2.2`。

DB12 报警读取范围为：

- `DB12.DBX0.0`～`DB12.DBX0.5`：压力、位移、称重传感器及通讯故障。
- `DB12.DBX0.6`～`DB12.DBX1.5`：7-1～7-8 电磁换向阀无动作。
- `DB12.DBX1.6`：油缸无动作。

报警位从 0 变为 1 时，系统创建报警、停止运行并锁定全部控制。报警位恢复为 0 后仍需管理员依次确认、恢复和关闭；软件不会自动恢复模式或动作。

## 反馈枚举契约

```text
当前通道：1尾轴、2中轴2、3中轴1、4飞轮、5为1#、6为2#
当前模式：0断开、1手动、2自动
当前动作：0空闲、1手动已启动、2上升、3下降、4快泄、5自动测试、6自动快泄
运行状态：0空闲、1运行、2暂停、3完成、4故障
自动阶段：0等待、1上升、2上升保持、3下降、4下降保持、5完成
```

PLC 应在自动采样序号递增后保持本次稳定的位移和顶升力，直到下一次采样。Java 按 `(runId, sequenceNo)` 幂等保存，先保存同周期最终采样，再处理完成状态。

## 参数保存规则

设置页保存当前通道时，只更新数据库、方案版本和审计日志，不操作 PLC。手动目标位移保存同样只写数据库；每次触发手动“上升”时，从数据库读取已保存目标位移，写入独立 REAL 点并回读一致后才发送上升脉冲。

每次触发“自动测量”时，后端从数据库读取自动目标位移、顶升速度、力值间隔和时间间隔，批量写入 PLC 并逐项回读；全部一致后才发送自动测量脉冲。标准值、总值和顶升系数只供 Java 计算或存储，不下发 PLC。力值间隔使用 PLC `INT`，单位 kN，只允许 1～32767 的整数。

若动作参数出现部分写入或回读不一致，本次上升或自动测量立即失败且不发送动作脉冲；操作员修复通讯或点位问题后可重新触发，系统会重新写入本次动作所需参数。
