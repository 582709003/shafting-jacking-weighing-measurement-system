### 压力间隔口径恢复

- 根据 PLC V21 离线程序，将配置字段由力值间隔（kN）恢复为压力间隔（MPa）。
- API、数据库、设置页、PLC 参数下发和模拟器统一使用 `pressureIntervalMpa`；PLC 地址仍为各通道原 `INT` 点。
- 新增 phase 14 增量迁移；旧 kN 列保留且不自动换算，迁移后需要重新配置六通道压力间隔。
- 模拟器按 PLC 的 0～100 MPa 量程线性生成内部压力，只保存位移和顶升力采样。
- 全量 81 个 Java 测试、原型检查、控制面板检查及 JavaScript 语法检查通过，JAR 打包成功。
