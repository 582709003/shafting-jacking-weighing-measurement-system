# 技术决策索引

既有技术决策及原因见根目录 `HANDOFF.md` 第 6 节；本文件只记录后续确认的变更。

## 2026-11-19：动作触发时下发 PLC 参数

- 模式接通只负责选择通道和确认模式。
- 手动目标在每次上升前下发；自动控制参数在每次自动测量前下发。
- 标准值、总值和顶升系数不下发 PLC，继续由 Java 计算或存储。
- 参数必须回读一致后才允许发送对应动作脉冲，避免 PLC 使用旧值。

## 2026-11-19：用户管理与密码维护边界

- 复用现有用户、角色和用户角色表，不新增数据库结构或依赖。
- ADMIN 可新增用户、分配多角色、修改他人角色和重置他人正式密码；禁止修改自身角色或通过管理接口重置自身密码。
- 系统始终保留至少一名启用的 ADMIN；所有用户修改本人密码时必须验证原密码，成功后当前会话立即失效。
- 管理员调整他人角色或密码不主动清理目标用户已有会话，新权限或密码在下次登录时生效。
- 登录账号统一转为小写，密码只保存 BCrypt 摘要，相关操作审计不包含明文密码。
