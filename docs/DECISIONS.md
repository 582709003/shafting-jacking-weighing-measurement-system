# 技术决策索引

既有技术决策及原因见根目录 `HANDOFF.md` 第 6 节；本文件只记录后续确认的变更。

## 2026-11-19：动作触发时下发 PLC 参数

- 模式接通只负责选择通道和确认模式。
- 手动目标在每次上升前下发；自动控制参数在每次自动测量前下发。
- 标准值、总值和顶升系数不下发 PLC，继续由 Java 计算或存储。
- 参数必须回读一致后才允许发送对应动作脉冲，避免 PLC 使用旧值。

## 2026-11-19：用户管理与密码维护边界

- 复用现有用户、角色和用户角色表，不新增数据库结构或依赖。
- ADMIN 可新增用户、分配多角色、修改他人角色和重置他人正式密码；禁止修改自身角色或通过管理接口重置自身密码。
- 系统始终保留至少一名启用的 ADMIN；所有用户修改本人密码时必须验证原密码，成功后当前会话立即失效。
- 管理员调整他人角色或密码不主动清理目标用户已有会话，新权限或密码在下次登录时生效。
- 登录账号统一转为小写，密码只保存 BCrypt 摘要，相关操作审计不包含明文密码。

## 2026-11-19：Session 过期统一退出

- 原生前端所有 API 请求统一经过 `apiFetch()`；任一请求返回 401 时使用 `location.replace` 跳转登录页，避免浏览器后退回到失效业务页。
- 复用现有每秒控制状态轮询检测无操作用户的会话过期，不新增重复定时器；登录页明确显示过期原因。

## 2026-11-24：恢复 PLC 压力间隔

- 根据 TIA Portal V21 离线导出的 `Recipe_Data.压力间隔` 及自动控制引用，平台参数恢复为 `pressureIntervalMpa`，单位 MPa，并继续按 PLC `INT` 限制为 1～32767 的整数。
- 压力间隔只控制 PLC/模拟器的保持采样时机；持久化采样仍只保存位移和顶升力，不恢复 `pressure_mpa`。
- 旧 `force_interval_kn` 数值缺少油缸有效面积，不能可靠换算为 MPa；增量迁移保留旧列并新增初值为 0 的压力间隔，要求重新配置。

## 2026-11-24：船体轴系示意与顶升动画

- 工作页使用仓库内联 SVG 绘制船体纵剖面，不引入外部图片、网络资源或前端依赖。
- 示意图按船尾到船首的物理顺序展示：尾轴、中轴2、中轴1、飞轮、1#、2#；顶部通道选择、接口和数据库顺序保持不变。
- 向上液流动画仅用于未暂停的手动上升，或自动测量 SSE 阶段为 `LIFTING` 的对应通道；检查、保持、下降、快泄、停止和暂停均不显示。
- 用户启用减少动画时保留静态向上箭头和“顶升中”文字，避免只靠动画表达状态。

## 2026-11-24：手动目标复用 PLC 顶升距离字段

- 手动目标仍在平台数据库独立保存，但 PLC 不新增手动目标地址。
- 每次手动上升前，将当前通道手动目标写入 DB100 对应配方的原有“顶升距离”字段并回读；自动测量启动前再以自动目标位移覆盖同一字段。
