# 问题索引

已解决问题、无效方案和待验证风险统一记录在根目录 `HANDOFF.md` 第 7、8 节。

- `docs/system-implementation-plan.md` 仍包含历史 Vue 规划；当前既定实现为原生静态前端，后续文档整理时再统一口径。
- 已修复待机状态无法切换通道：`syncCurrentRun()` 曾将 `IDLE` 通道误标为 `RUNNING`，现仅在手动动作、自动测量或全局快泄期间建立运行态和实时订阅。
- 已解除报警 SSE 对其他初始化请求的依赖：监听现在优先建立，记录、报警列表或控制状态加载失败时仍可接收新报警。
- 用户管理复用现有三张权限表；管理员修改他人角色或密码不会强退目标用户，页面明确提示下次登录生效。
- 已修复 Session 过期后页面仍停留在业务界面的问题：API 401 现在统一触发退出并显示过期提示。
- 已纠正平台“力值间隔（kN）”与 PLC “压力间隔（MPa）”不一致的问题；旧 kN 配置不自动换算，执行 phase 14 后必须重新录入六通道压力间隔。
- 已修复旧轴线图把下降、快泄和整个自动测量过程都显示成向上流动的问题；当前只在手动上升或自动 `LIFTING` 阶段点亮对应通道。
- 已移除对六个新增手动目标 PLC 地址的错误依赖；手动上升与自动测量按各自动作时机写入同一个现有“顶升距离”字段。
